# 🏥 Pima Indians Diabetes Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Healthcare](https://img.shields.io/badge/Healthcare-ML-red.svg)

## 📖 Overview

Binary classification model to predict diabetes onset in Pima Indian women based on diagnostic measurements. Uses medical features like glucose levels, BMI, and insulin to predict diabetes risk.

## 🎯 Features

- Diabetes risk prediction
- Medical feature analysis
- Model performance comparison
- Healthcare insights

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Pima-Indians-Diabetes-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Medical Features

- Glucose, Blood Pressure
- Insulin, BMI
- Age, Pregnancies
- Diabetes Pedigree Function
